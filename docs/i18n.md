# Translations (en / ru / uz)

The app speaks English, Russian and Uzbek (Latin script). The user's language lives
in `users.language`. New users get it from Telegram's `language_code`, and they can
change it in Settings.

## How it works

- `tgcloud/lib/i18n/core.js`: gettext style. **The English text is the key**, so
  untranslated strings fall back to English.
  - `t('Rest day')`, `t('Saved {w}', { w })`
  - `t.n(count, '{n} set', '{n} sets')`: plural entries are keyed by the English
    *plural* form. Russian value = `[one, few, many]` (`'{n} подход', '{n} подхода', '{n} подходов'`).
    Uzbek value = a plain string (`'{n} ta podxod'`), because Uzbek doesn't inflect after numbers.
- Mini App: `import { t, cname } from '../lib/i18n.js'`. Dictionaries live in
  `src/i18n/*.js`, one file per area, each `export default { ru: {…}, uz: {…} }`,
  merged in `src/lib/i18n.js`.
- Bot and reminders: `tr(user)` from `tgcloud/lib/i18n/bot.js` returns a `t` for that user.
- Friends, challenges, achievements and programs: strings both sides show (server errors,
  chat texts, achievement and program names) live in `tgcloud/lib/i18n/friends.js`, which the
  bot and the Mini App both merge. Mini App-only friends text is in `src/i18n/social.js`.
  `test/social.mjs` fails if one of those strings lacks ru or uz in the dictionary its runtime loads.
- Built-in exercise and food names: `tgcloud/lib/i18n/catalog.js`. Use `cname(name)` at
  display time. A name that isn't built-in (e.g. a user's own exercise) comes back unchanged.
- Call `t()` **at render time**, never in a module-level constant: the language can
  change at runtime. Module-level label maps stay English, and you wrap them at use:
  `t(MEAL_LABEL[meal])`.
- Keys must match the English text exactly, including punctuation, `…` and `—`.

## Voice

**Russian**: informal **«ты»**, short and friendly, the way people talk at the gym.
Not bureaucratic, and no word-for-word calques from English. Use real gym words:
подход, повторы (повт.), рабочий вес, разминка, жим лёжа, становая, присед, отдых,
сушка, масса, тренировка, рекорд. Use «ё» where it belongs. Examples: «Погнали!»,
«Отдых окончен — следующий: …», «Сохранил 82,4 кг».

**Uzbek (Latin)**: polite but warm **«siz»**, the everyday Tashkent register, not
literary or official. Use ‘ (U+2018) in o‘ g‘ (O‘zbekcha, bog‘lash) and ’ (U+2019)
for the tutuq belgisi (ma’lumot, sur’at). Uzbek gym-goers mix in Russian gym terms,

Units (kg, lb, kcal, kJ, g, ml, L, km, min) stay as symbols. In Russian, use кг, г, мл,
л, км, мин, сек when they're part of a sentence. Values that come from `fmt.w()`
(`82 kg`) are formatted by the units module and stay as they are.
